ACC setup in 60 seconds

ACC streams telemetry to your phone once its broadcast API is switched on — and RaceHero Link switches it on for you. Nothing to move, nothing to edit, nothing to sign into.

⬇ Download RaceHero Link
1

Install RaceHero Link on your gaming PC

Link turns on ACC's telemetry API by itself — it writes ACC's one tiny config file so you don't have to — and it keeps it on: if the game or a cleanup tool ever rewrites that file, Link spots it and repairs it.

2

Load any session

Your phone finds the game over WiFi by itself and starts coaching. Just keep your phone and PC on the same WiFi.

✓ Done? Go back to the RaceHero app → RACE SIM → pick Assetto Corsa Competizione → START. The app detects the game automatically.

No Link? Set it by hand — once, takes a minute

ACC needs that one tiny config file; Link normally writes it for you. Without Link, place it yourself — download it, then put it in ACC's Config folder (create the folder if it isn't there):

⬇ Download broadcasting.json

Documents\Assetto Corsa Competizione\Config\broadcasting.json

Then load any session, same as step 2 above. Do this once — it stays enabled forever.
